# موقع مديرية تنفيذ قضاء المحاويل

**جمهورية العراق — وزارة العدل — دائرة التنفيذ / مديرية تنفيذ قضاء المحاويل**

موقع إلكتروني تعريفي وخدمي للمديرية، يعمل على الحاسوب والهاتف، ويدعم الوضع الليلي وتكبير الخط.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `styles.css` | التصميم |
| `script.js` | التفاعل والبيانات (الخدمات، الأخبار، شريط الإعلانات) |
| `fb-news.php` | مزامنة أخبار صفحة فيسبوك (يعمل فقط على استضافة تدعم PHP) |
| `assets/` | الشعار وصورة مديرة المديرية |
| `data/meta.json` و `data/idx/` | بيانات البحث عن رقم الإضبارة (مشفّرة بـ PBKDF2 و AES-256، مقسّمة على 64 ملفاً) |
| `tools/access_to_json.py` | أداة تحويل قواعد Access إلى ملفات البحث |
| `tools/sources.example.json` | قالب إعدادات عدة ملفات Access |
| `ACCESS-IMPORT.md` | خطوات تحديث بيانات البحث من Access |
| `tools/complaints-apps-script.gs` | كود حفظ الشكاوى في Google Sheets |
| `COMPLAINTS-SETUP.md` | خطوات تفعيل حفظ الشكاوى |

## تعديل المحتوى

- **الخدمات والأخبار وشريط الإعلانات:** في أعلى ملف `script.js` (المصفوفات `SERVICES` و `NEWS` و `TICKER`).
- **العنوان وأوقات الدوام والنصوص:** في ملف `index.html`.

## البحث عن رقم الإضبارة (من قاعدة Access)

يبحث المراجع باسم الدائن أو اسم المدين (ثلاثي أو رباعي) فيظهر له رقم الإضبارة وسنتها ونوع القرار.
البيانات في `data/meta.json` و `data/idx/`، وتُولَّد من ملفي Access الخاصين بالمديرية
(«الاجراءات التنفيذية» و«برنامج الديون») بالأداة `tools/access_to_json.py`.

لتحديث البيانات اتبع **[ACCESS-IMPORT.md](ACCESS-IMPORT.md)** باختصار:

1. `python tools\access_to_json.py --config tools\sources.json`
2. ارفع ملفات `data/idx/` الـ64 ثم `data/meta.json` إلى المستودع لتستبدل القديمة.

> 🔒 الأسماء لا تُرفع إلى GitHub. لكل اسم مُعرِّف ومفتاح مشتقان بـ PBKDF2 (100,000 تكرار)،
> ونتيجته (رقم الإضبارة والسنة والنوع) مشفّرة بـ AES-256-GCM لا يفكّها إلا من يكتب الاسم الصحيح.
> لا ترفع ملف قاعدة Access نفسه أو أي ملف CSV فيه أسماء إلى المستودع.

## مزامنة الأخبار من فيسبوك

- صندوق "آخر منشورات الصفحة" يعمل تلقائياً على أي استضافة، ومنها GitHub Pages.
- بطاقات الأخبار المتزامنة تحتاج استضافة تدعم PHP ورمز وصول للصفحة. خطوات الإعداد مكتوبة في أعلى ملف `fb-news.php`.
- على GitHub Pages تبقى الأخبار المكتوبة في `script.js` ظاهرة مع صندوق فيسبوك المباشر.

> ⚠️ لا ترفع رمز الوصول (Token) أو ملف `fb-token.php` إلى GitHub أبداً.

## الشكاوى والمقترحات

تُحفظ رسائل نموذج الشكاوى في جدول Google Sheets خاص بالمديرية عبر Google Apps Script
(الكود في `tools/complaints-apps-script.gs`). خطوات التفعيل في **[COMPLAINTS-SETUP.md](COMPLAINTS-SETUP.md)**.
قبل التفعيل لا يُرسل النموذج أي بيانات، ويخبر المواطن بأن الإرسال الإلكتروني غير مفعّل.
